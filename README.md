# 📌 The Lost Packet

The Lost Packet è un gioco RPG ambientato nel mondo dell'informatica e delle reti.
Il giocatore dovrà affrontare diversi avversari attraverso un sistema di combattimento a turni, utilizzando attacchi e abilità speciali, con l'obiettivo di recuperare il pacchetto TCP perduto.

---

## 🚀 Come eseguire il progetto

### Prerequisiti
- Java 25 (LTS)
- Gradle

### Istruzioni

```bash
git clone https://github.com/TommySeb/TheLostPacket
cd TheLostPacket
```

### Build del progetto
```bash
./gradlew build
```

### Esecuzione
```bash
./gradlew run
```
